# 🏷️ Sistema de Ícones — Direito Ambiental na Palma da Mão

Este documento estabelece o padrão visual utilizado no repositório **Direito Ambiental na Palma da Mão**.

Os ícones têm a função de facilitar a identificação, revisão, atualização e priorização das informações jurídicas e acadêmicas, criando uma linguagem visual padronizada para o estudo de Direito Ambiental.

---

# 📖 Padrão de utilização

Os ícones devem ser utilizados **antes da informação que identificam**, mantendo o mesmo padrão em todo o repositório.

### 📜 Lei / Legislação

```text
📜 Lei nº 9.605/1998 — Lei de Crimes Ambientais
```

### ⭐ Legislação Prioritária

```text
⭐ Legislação Prioritária — Lei nº 6.938/1981
```

### 💡 Conceito

```text
💡 Conceito — Licenciamento ambiental
```

### 🔑 Verbo da Lei

```text
🔑 Verbo — causar
```

Quando houver mais de um verbo nuclear relevante:

```text
🔑 Verbos — destruir, danificar, utilizar
```

### ⚖️ Pena / Sanção

```text
⚖️ Pena/Sanção — multa e/ou pena prevista no dispositivo
```

### 🟢 Caiu em prova

Sempre registrar **banca, concurso e ano**, quando essas informações estiverem disponíveis:

```text
🟢 Caiu em prova — Concurso X, ano XXXX
```

Preferencialmente:

```text
🟢 Caiu em prova — Banca X, Concurso Y, 2025
```

### 🔴 Questão anulada

Registrar a identificação da prova:

```text
🔴 Questão anulada — Banca X, Concurso Y, 2024
```

### ❓ Dúvida

```text
❓ Dúvida — Qual é a diferença entre autorização e licença ambiental?
```

### ⚠️ Corrigir / Atualizar

```text
⚠️ Corrigir/Atualizar — verificar alteração legislativa posterior
```

### ✅ Correto / Confirmado

```text
✅ Correto — informação conferida em fonte oficial
```

### 🔗 Fonte Oficial

```text
🔗 Fonte Oficial — Planalto
```

### 🆕 Atualização

```text
🆕 Atualização — dispositivo alterado pela Lei nº X.XXX/AAAA
```

### 📌 Ponto-chave

```text
📌 Ponto-chave — competência comum dos entes federativos
```

### 🧠 Memorização

```text
🧠 Memorizar — requisito essencial para o licenciamento
```

### 📝 Anotação

```text
📝 Anotação — verificar relação com legislação estadual
```

# 🔗 Combinação de Ícones

Quando uma informação possuir mais de uma característica, os ícones podem ser combinados.

### Exemplo 1 — legislação prioritária que caiu em prova

```text
⭐ 📜 Lei nº 9.605/1998 — Lei de Crimes Ambientais
🟢 Caiu em prova — Banca X, Concurso Y, 2024
```

### Exemplo 2 — conceito prioritário

```text
⭐ 💡 Conceito — Licenciamento ambiental
```

### Exemplo 3 — dispositivo com verbo e sanção

```text
🔑 Verbo — causar
⚖️ Pena/Sanção — conforme previsto no dispositivo
```

### Exemplo 4 — informação que precisa ser verificada

```text
⚠️ ❓ Dúvida — verificar vigência e alterações posteriores
```

# 📌 Regras de Padronização

1. **O ícone deve aparecer antes do texto.**
2. **Manter a mesma função para cada ícone em todo o projeto.**
3. **Não utilizar ícones diferentes para o mesmo significado.**
4. **Quando possível, identificar banca, concurso e ano nas questões de prova.**
5. **Informações jurídicas devem ser verificadas em fontes oficiais.**
6. **O marcador 🟢 deve ser utilizado somente quando houver registro verificável de cobrança em prova.**
7. **O marcador 🔴 deve ser utilizado somente quando houver confirmação de anulação da questão.**
8. **O marcador ⭐ indica prioridade de estudo e não necessariamente maior hierarquia jurídica.**
9. **O marcador ⚠️ indica necessidade de revisão, atualização ou correção.**
10. **Os ícones devem complementar a informação, não substituí-la.**

## 🎯 Objetivo do Sistema

O sistema de ícones transforma o material de estudo em uma estrutura visual de identificação rápida:

**📜 Norma → ⭐ Prioridade → 💡 Conceito → 🔑 Verbo → ⚖️ Sanção → 🟢 Prova → 🧠 Revisão**

A utilização padronizada permite localizar rapidamente os pontos mais importantes durante a revisão e facilita a organização do conhecimento no **Gemini Notebook** e no GitHub.
